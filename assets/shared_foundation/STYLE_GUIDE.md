# Iron-Mario retro-future toybox style

Palette: night `#101c28`, panel `#1b2c3a`, warm paper `#faf3df`, teal `#66dcca`, coral `#ff9687`, gold `#f2c15d`, violet `#b8a0ec`, and reactor blue `#91c5ff`.

Use a 4px dark outline for primary silhouettes, 2px for secondary props, and a single upper-left light direction. Keep the center 55% of a board clear for the existing input targets. Put dense props in the outer thirds. Gameplay actors use the brightest accent; background objects stay one luminance step quieter.

Every kit is layered as `background`, `room`, `props`, `effects`, and `foreground`. Reduced-motion mode removes animated particles and uses static glow rings, stripes, or icon pulses.

The visual target is a chunky retro-future toybox: tactile machinery and playful shapes with cinematic accent lighting. It is not a raw pixel-pack collage and it does not imitate a named comic franchise.
