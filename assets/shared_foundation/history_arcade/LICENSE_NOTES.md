# History Arcade asset provenance
Every PNG listed in manifest.json is newly drawn for this project with integer-grid primitives. No historical game's art, logo, character or level layout is copied. The game concept images are art studies, not screenshots of finished games.

The new curator NPC studies are assembled from the user's full Modern Interiors character-generator layers. They are stored only under source_art/history_arcade/curators, with exact recipes and Aseprite sources. Full-pack license allows game use and editing with LimeZu credit, and prohibits standalone redistribution. They are excluded from this shareable kit and browser package.

Character Generator 2.0 did not expose a usable window through the Windows helper. No new application-generated output is claimed. Its output rights remain unverified. Free/demo pack pixels are excluded. Full Fantasy Battlers and Fungus Cave were visual references only for the new original artwork.

Source notes: source_art/history_arcade/source_notes.json. Public publication license for the project's original artwork must be stated when the new product is released; this kit does not relicense third-party content.
