# Arc Break asset provenance

The lab set uses selected tiles/objects and a premade character from the owner's
Modern Interiors Full pack by LimeZu: https://limezu.itch.io/moderninteriors

The included Full Version license permits commercial and non-commercial project
use and editing, requires credit, and prohibits reselling or redistributing the
raw assets. The original asset pack is not included here; only the small PNGs
used by this prototype are copied into the project.

`character_generator/scientist_premade_20.png` is a premade character sprite
from the Character Generator component of the same Modern Interiors Full pack.
Character Generator 2.0 itself is a separate GPL-3.0 tool; its executable and
source code are not bundled in the game.

The cave, conductive fungus, repulsor effects, character armor, and all Arc Break
gameplay artwork are original code-drawn elements. Fungus Cave and Fantasy
Battlers assets are intentionally not used until their redistribution terms are
confirmed.
