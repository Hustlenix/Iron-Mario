# Original Four: superhero selection milestone

Four original public identities explore powered flight (Solstice), gravity acrobatics (Vector), tactical stealth (Umbra), and dimensional magic (Prism). Their costumes, faces, emblems, silhouettes and effects were created for this project. Artwork was generated with the built-in image generation tool, inspected, and copied into `assets/roster`. All four PNGs preserve their generated alpha channels; no scraped game art was used.

The art direction specified full-body comic illustrations on transparent backgrounds: coral/ivory turbine armor with a wedge visor and forearm lance; a teal/magenta gravity runner with silver curls and gold ribbon anchors; a silver hooded nightwatch guardian with an indigo coat and green smoke canisters; and a white-haired dimensional weaver with mint/plum robes, floating prisms and crystalline shards. Avoidance constraints explicitly excluded franchise costumes, logos and signatures. Generation prompts emphasized original silhouettes and identities rather than superficial renaming.

The selection screen includes portrait switching, entrances, idle cloth movement, four timed power demonstrations, original synthesized sound cues, keyboard and controller commands, persistent equipment, reduced motion, and links into four existing matching arcade games. These are presentation demonstrations. Character selection remains cosmetic in the existing 105-game arcade; this milestone does not claim new character-specific combat systems or skeletal animation.

Saved hero IDs are preserved to retain equipment and mastery history: dart / bolt / echo / frost map to Solstice / Vector / Umbra / Prism. Other existing saved hero IDs remain valid. The selector follows the viewport in CSS pixels, accounting for the browser device pixel ratio so mobile text and 48-pixel actions remain usable. Leaving it restores the existing 960×540 gameplay canvas and orientation guard.

The private Marvel/DC reference exploration is confined to ignored `build/private-superhero-concept`, outside public exports. The image tool rejected the requested franchise character illustrations without a specific reason (category `other`). The private fallback therefore uses named references and original abstract power motifs; it is not a completed illustrated likeness mockup.

The broader home, catalog, and 105-game visual overhaul remains a later milestone. No new minigames were added in this change.

Browser verification exposed an existing filesystem durability issue: a successful virtual profile write did not update the durable IndexedDB profile in the tested export. Changing to a direct final-path write did not resolve it and was reverted. This milestone stores only the roster's validated hero and reduced-motion preferences through two synchronous browser localStorage keys, then restores those preferences into the existing profile state. The browser reload test verifies that equipment preference. Native saves retain their atomic temp/backup/rename flow. Broader browser record durability remains a separate unresolved issue and is not certified by the selector checks.

Local validation completed: all fourteen suites passed, totaling 4,455 checks with zero failures. The selector suite covers 274 cases, including a real blocked-save fixture and rollback. Twenty-two native GPU screenshots were captured and reviewed. Chromium verified all four selection/power states, immediate equipped-hero reload, 375/390/430 CSS widths, 390px touch interaction at device pixel ratio 3, and the established game/pause/result path without console errors or missing assets. Both Web and Windows exports completed; the exported Windows executable launched without engine errors. These checks do not certify a physical touchscreen, controller, or mobile GPU frame rate.
