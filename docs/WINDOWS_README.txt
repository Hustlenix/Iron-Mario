IRON-MARIO: THE REACTOR RESCUE - WINDOWS x86-64

1. Extract the ENTIRE downloaded ZIP into a folder.
2. Keep the executable and matching .pck file together.
3. Double-click Iron-Mario.exe (or Super-Micro-Heroes.exe in CI packages).

Do not run the EXE from inside the ZIP or move it away from its PCK.
No Godot installation is needed to play an exported build.
Requires 64-bit Windows 10 or newer and an OpenGL 3.3-compatible display driver.

HOME
START ADVENTURE: Iron Mario, three authored stages and the Scrap King boss.
ARCADE: all twenty cabinets, each with its own objective and controls.
QUICK GAMES + TOURNAMENT: seven short games, Tournament and bonus Flappy.
The larger historical arcade opens as a separate online Vault from Arcade.

CONTROLS
Adventure: A/D or Left/Right move; W/Up/Space jump; hold E/Enter to blast.
Arcade: read the cabinet briefing, then Space/Enter or PLAY starts the game.
Arrows/WASD move; Space/E/Enter is Action; Z/U is the secondary action.
Paddle games also follow the mouse; board cells and interception points are clickable.
Escape pauses and shows the controls. Enter/Space resumes or replays a result.
R restarts the current game. Tab/arrows navigate menu buttons; Enter selects.

Settings includes volume, mute and reset progress. TOUCH: ON previews phone controls.
Arcade Profile equips an original bonus character; the adventure always stars Iron Mario.
Adventure uses three hulls; the original Tournament retains five reactor lives.
Stage progress, individual arcade records, settings and existing profiles are saved.

TROUBLESHOOTING
Extract both files again if Windows reports a missing game pack.
For a black screen, update the display driver from the PC/GPU manufacturer.
For diagnostics, open a terminal in the extracted folder and run:
  .\Iron-Mario.exe --log-file iron-mario.log
Use .\Super-Micro-Heroes.exe instead if your package has that filename.
Share iron-mario.log and the exact Windows error when reporting an issue.
