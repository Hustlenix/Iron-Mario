IRON-MARIO - WINDOWS x86-64

1. Extract the ENTIRE downloaded ZIP into a folder.
2. Keep Iron-Mario.exe and Iron-Mario.pck together.
3. Double-click Iron-Mario.exe.

Do not run the EXE from inside the ZIP or move it away from its PCK.
No Godot installation is needed to play the exported game.
Requires 64-bit Windows 10 or newer and an OpenGL 3.3-compatible display driver.

Controls: A/D or Left/Right to move; W/Space to jump; mouse to click/drag.
R restarts a microgame. Tab/arrows navigate menus; Enter selects.
Settings includes volume, mute, and reset progress.
Seven missions, five reactor lives; the original bonus Flappy game is retained.

Troubleshooting:
- Extract both files again if Windows reports a missing game pack.
- For a black screen, update the display driver from the PC/GPU manufacturer.
- To capture diagnostics, open a terminal in this folder and run:
  .\Iron-Mario.exe --log-file iron-mario.log
  Share iron-mario.log and the exact Windows error when reporting an issue.
