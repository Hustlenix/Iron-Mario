# Dino Dash artwork

Original OnlyEducation artwork. Teal Moss Rex, coral neck band, gold eye and belly. No third-party sprites.

runner.aseprite has five tagged frames: run-left, run-right, jump, duck and bump. tools/build_dino_art.py builds the integer-grid source; tools/export_dino_art.lua creates the editable Aseprite timeline. The public PNG is exported from that timeline.
