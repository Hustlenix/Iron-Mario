# Independent game contract
Canvas 480x320 at 60Hz fixed timestep. No DOM/global listeners/timers/storage inside games. Each game ESM exports createGame(api). api={rng:()=>number in [0,1), sound:(name)=>void, sprite:(ctx,id,x,y,options?)=>void}. Sound names hit,score,lose,win,move. Assets IDs pieces_scout,pieces_crate etc (32x32), tiles_*16x16. sprite optional fallback for unit tests via api.sprite?.(...).
Returned object: {state, update(dt,input), draw(ctx)}. state object is mutable and contains status:'playing'|'won'|'lost', score:number, message:string, plus game-specific fields; status change only after actual gameplay outcome. Optional dispose() cleanup. Initial state playing; host owns ready screen/pause/restart. update receives input={down(action):bool,pressed(action):bool,pointer:{x,y,down,pressed,active}}. Pointer coordinates native 480x320. Actions left,right,up,down,action,secondary. Arrow/WASD,Space/Enter action,Z/Backspace secondary. Pressed cleared after ONE simulation update. Touch Dpad/buttons provided by host, canvas tapping supported. Never map platform pause/restart internally. Poll fresh pointer only when active/down as appropriate. Input has no methods besides down/pressed. Reset by recreateGame with same seed. Deterministic no Math.random, Date or external dependencies. State inspected for QA only; browser test hooks read-only snapshots. Pure JS modules import ../engine/math.js if needed: clamp(v,min,max), rects(a,b), distance(a,b). Drawing can be independent Canvas2D primitives, integer coordinates preferred, use existing assets where useful. Game must fit 480x320 including native HUD, navy background #152536, paper #fff0cf, teal #61d5c8,gold #ffc56a,coral #fa8068.
Each game has its OWN logic. Meaningful progressive difficulty/levels. Functional enemy if relevant. Complete win/loss loop. Help instructions documented. Node tests under tests/arcade/*.test.mjs using node:test/assert, import modules relatively ../../onlyeducation/arcade/games/*.js. Test seeded reproducibility, collision/game-specific outcomes. Tests may fixture state for precise boundary coverage; distinguish from browser input evidence. Don't edit other agents' game files or platform/registry. No git operations from workers.

Optional retry(): boolean may recover a lost round in the existing game instance, preserving earned earlier progress. The host invokes it only from an ended loss. It must set status to playing and return true; it must not award points, increment clears or create global resources. Full Restart still recreates the game. Local original artwork can use catalog.assetManifest and catalog.cover; packager includes their PNG/JSON files.
